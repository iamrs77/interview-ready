## 1. Core Basics

**[var, let, const and Scope](./core-basics/variables-and-scope.mdx)**

- **`var`** is function-scoped. **`let`** and **`const`** are block-scoped (they stay inside `{ }`).
- **`const`** can't be reassigned, but an object or array in a `const` can still be changed.
- Use **`const` by default**, `let` when the value changes, and never `var`.
- **Scope chain:** JavaScript looks for a name in the current scope, then outward to global. Not found means **ReferenceError**.
- **Shadowing:** an inner variable with the same name hides the outer one. The outer one doesn't change.
- **Lexical scope:** where a function is **written** decides what it can see, not where it is called.

**[Hoisting and Execution Context](./core-basics/hoisting-and-execution-context.mdx)**

- Every execution context has a **creation phase** (set up memory) and a **run phase** (run line by line).
- **`var`** is hoisted as `undefined`. **Function declarations** are hoisted in full, so you can call them early.
- **`let`, `const` and `class`** are hoisted but locked in the **temporal dead zone**: "Cannot access 'x' before initialization".
- A function in a `var` gives **"x is not a function"** if called early. In a `const`, it's a TDZ error.
- In the TDZ, even **`typeof` throws**.
- The **call stack** pushes a context on every call and pops it on return. Endless recursion: **"Maximum call stack size exceeded"**.

**[Types and Coercion](./core-basics/types-and-coercion.mdx)**

- **8 types:** string, number, boolean, null, undefined, symbol, bigint (the 7 primitives) and object.
- **`typeof` quirks:** `typeof null` is `"object"`, `typeof NaN` is `"number"`, `typeof []` is `"object"`. Use `=== null` and `Array.isArray`.
- **`===`** never converts. **`==`** converts: `null == undefined` only, booleans and strings become numbers, objects become primitives.
- **`+` with a string joins:** `"5" + 3` is `"53"`. Other math converts to numbers: `"5" - 3` is 2.
- **8 falsy values:** `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`. `"0"`, `[]` and `{}` are truthy.
- **NaN is not equal to itself.** Check with `Number.isNaN`, not the global `isNaN`.

**[Operators, Template Literals and Comments](./core-basics/operators-and-syntax.mdx)**

- **`%` is a remainder** and keeps the left sign: `-7 % 3` is -1. `**` is power, and `-2 ** 2` is a SyntaxError.
- **`a || b`** gives the first truthy value. **`a && b`** gives the first falsy value. The right side may never run.
- **`??`** falls back only on `null` or `undefined`, so it keeps 0, `""` and `false`. Use it for defaults.
- **`i++`** gives the old value, **`++i`** the new one. It only matters inside a bigger expression.
- **Precedence:** `!` and `typeof` run before math, `*` before `+`. When unsure, add brackets.
- A **tagged template** calls a function with the text parts and the values. **JSDoc** (`/** @param */`) gives editors type hints.

**[Control Flow and Loops](./core-basics/control-flow-and-loops.mdx)**

- **`if / else if`** runs only the **first** true branch. Always use braces.
- **`switch`** compares with **`===`**. Without `break`, it **falls through** into the next cases.
- **`for`** for counting, **`while`** for an unknown number of rounds, **`do...while`** runs **at least once**.
- **`break`** stops the loop, **`continue`** skips to the next round. A **label** lets `break` stop an outer loop.
- **`for...of`** gives **values** (arrays, strings, Map, Set). **`for...in`** gives **keys** as strings, including inherited ones.
- `forEach` can't `break`, and `for...of` on a plain object throws: use `Object.entries`.

**[Value vs Reference](./core-basics/value-vs-reference.mdx)**

- **Primitives** are copied by value. **Objects and arrays** are copied by **reference**: `const b = a` shares the same object.
- **Shallow copy** (`[...array]`, `{ ...object }`): only the first level is copied. Nested objects are **shared**.
- **Deep copy**: every level is copied, so nothing is shared.
- `JSON.parse(JSON.stringify(x))` works only for **plain data**. Dates become strings, functions and `undefined` are dropped, Maps and Sets become `{}`.
- **`structuredClone(x)`** is the modern deep copy. It keeps Dates, Maps and Sets, but can't copy functions.

## 2. Functions

**[Functions in Depth](./functions/functions.mdx)**

- **Declarations** are hoisted with their body. **Expressions** exist only after their line runs.
- **Arrow functions** have no own `this`, no `arguments`, and can't be used with `new`.
- Arrow **without braces** returns its value. **With braces**, write `return`. Objects need `() => ({ ... })`.
- **Defaults** replace only `undefined`. **Rest** `...args` is a real array. `arguments` is not.
- Arguments are passed **by value**. For an object, the value is a **reference**: changing its contents is seen outside, giving the parameter a new object isn't.
- Functions are **values**: `fn` is the function, `fn()` runs it. An **IIFE** runs right where it's written.
- A **callback** is a function you pass in, to be called later (async) or right away (like `map`).

**[Closures](./functions/closures.mdx)**

- A **closure** = a function + the variables from where it was **created**. It works even after the outer function returns.
- It keeps a **link to the variable**, not a copy of the value.
- Use it for **private state**: counters, bank accounts, `once`.
- **`var` loop bug:** one shared `i`, callbacks run later, so `4 4 4`. Fix with **`let`** (a new `i` each round) or an **IIFE**.
- Linked variables **stay in memory**. Clear timers and listeners so big data can be freed.

**[The this Keyword](./functions/this-keyword.mdx)**

- `this` is decided by **how** a function is called. Look **left of the dot** at call time.
- The rules, strongest first: **new** → **call / apply / bind** → **obj.method()** → **plain call** (`undefined` in strict mode, else the global object).
- **Arrow functions** have no own `this`: they use the surrounding `this`, and `call` or `bind` can't change it.
- **Passing `obj.method`** loses `this`. Fix with `() => obj.method()` or `obj.method.bind(obj)`.
- **Classes** are strict, so a lost `this` throws. Fix with `bind` in the constructor or an **arrow class field**.

**[call, apply and bind](./functions/call-apply-bind.mdx)**

- **call** and **apply** run the function **now**. **bind** returns a **new function** for later.
- **A**pply = **A**rray of arguments. **C**all = **C**ommas.
- **Borrowing:** `Array.prototype.join.call(arguments, ",")` uses a method on another object.
- `bind(null, 2)` **pre-fills** arguments: partial application.
- A bound `this` is **final**. Arrow functions ignore all three for `this`.
- Still use `bind` for **callbacks you must keep or remove later**, and class methods passed around.

**[Higher-Order Functions and Currying](./functions/higher-order-functions-and-currying.mdx)**

- A **higher-order function** takes a function, returns one, or both: `map`, `debounce`, `memoize`.
- **Currying:** `f(a, b, c)` → `f(a)(b)(c)`, one argument per call. **Partial application:** fix some arguments now, pass the rest later.
- **pipe** runs functions left to right. **compose** runs them right to left: `compose(f, g)(x)` is `f(g(x))`.
- **Memoization** caches results by input in a closure. Only for **pure** functions.
- All of these work because of **closures**.

## 3. Objects and Arrays

**[Objects in Depth](./objects-arrays/objects.mdx)**

- Create objects with a **literal** `{}`, a **constructor** (`new`), or **`Object.create(proto)`**. `Object.create(null)` has no prototype at all.
- **`Object.keys`, `values`, `entries`** give arrays of the object's **own** keys, values or pairs. **`for...in`** also visits inherited keys.
- Every property has 3 flags: **writable, enumerable, configurable**. `defineProperty` sets any flag you leave out to `false`.
- **Getters and setters** run when a property is read or written: `get fullName()`, `set fullName(value)`.
- **preventExtensions** (no adding) → **seal** (no adding or deleting) → **freeze** (no changes at all). All are **shallow**.
- **`const` is not `freeze`:** it locks the variable, not the object.

**[Array Methods](./objects-arrays/array-methods.mdx)**

- **`map`** = new array, same length, each item changed. **`forEach`** = just runs the callback, gives back `undefined`.
- **`filter`** = all matches (an array). **`find`** = the first match or `undefined`. **`some`** = any match? **`every`** = all match?
- **`reduce`** carries a running total. **Always pass a start value**, and always return the total.
- **`sort`, `reverse`, `splice`, `push`, `pop`** change the original. **`toSorted`, `toReversed`, `toSpliced`, `with`** don't.
- The default **`sort` compares as text**: use `(first, second) => first - second` for numbers.
- On an empty array, `some` gives `false` and `every` gives `true`.

## 4. OOP in JavaScript

**[Constructor Functions and new](./oop/constructor-functions-and-new.mdx)**

- **OOP** = data and the methods that work on it, together in one object.
- A **constructor function** fills in `this` and is called with **`new`**. Capital first letter by habit.
- **`new` does 4 steps:** create `{}` → link it to `Fn.prototype` → run `Fn` with `this` = the new object → return it.
- Put methods on **`Fn.prototype`**: one shared copy instead of one per object. No arrow functions there.
- **`instanceof`** checks whether `Fn.prototype` is on the object's prototype chain.
- Forgetting `new` gives `undefined` and leaks globals. A class always throws instead.

**[Prototypes and the Prototype Chain](./oop/prototypes.mdx)**

- Every object has a hidden link to its **prototype**. A missing property is looked up **along the chain**, until `null` gives `undefined`.
- **Reading walks the chain, writing doesn't:** a write creates the property on the object itself.
- **`prototype`** is on functions (what `new` objects will get). **`__proto__`** is every object's link. `rex.__proto__ === Dog.prototype`.
- Use **`Object.create(proto)`** to make a linked object and **`Object.getPrototypeOf(obj)`** to read the link.
- **Classes are built on prototypes:** methods go on `Class.prototype`, and `extends` = `Object.create(Parent.prototype)`.
- Keep **methods** on the prototype and **data** on each object.

**[Classes](./oop/classes.mdx)**

- A **class** is a blueprint. An **object** (instance) is one thing made from it with `new`.
- The **constructor** sets up a new object. **Methods** are its actions. **`this`** is the current object.
- **Instance properties** belong to each object. **Static** members belong to the class: `Calculator.add(5, 7)`.
- A **getter** runs when a property is read. A **setter** runs when it's changed, and can refuse bad values.

**[Encapsulation](./oop/encapsulation.mdx)**

- **Encapsulation** = hide the data inside the object, and allow access only through its methods.
- A `#` name is **private**: only code inside the class can use it. Using it outside is a **SyntaxError**.
- **public**: everyone (the default in JavaScript). **private**: only the class (`#` in JavaScript). **protected**: the class and its children (not in JavaScript).

**[Abstraction](./oop/abstraction.mdx)**

- **Abstraction** = show only what the user needs, and hide how it works.
- A **private method** (`#startEngine()`) hides the details. Outside code calls only the simple method (`start()`).
- **Abstract class:** can't be created directly, only extended. Child classes must write its abstract methods.
- **Interface:** a list of methods and properties a class must have.
- JavaScript has no abstract classes or interfaces. **TypeScript** has both.

**[Inheritance](./oop/inheritance.mdx)**

- **Inheritance:** `class Child extends Parent`. The child gets the parent's properties and methods, and can add its own.
- A child can **override** a parent method by writing its own version.
- `super(...)` calls the parent's constructor. `super.method()` calls the parent's version of a method.
- No constructor in the child: the parent's constructor runs automatically.
- A child constructor must call `super()` **before using `this`**, or you get a `ReferenceError`.

**[Polymorphism](./oop/polymorphism.mdx)**

- **Polymorphism** = the same method call behaves differently, depending on the object.
- **Overloading:** same name, different parameters, same class. Only in **TypeScript**: several signatures, **one** implementation that handles them all.
- **Overriding:** a child class redefines a parent's method with the same name and parameters.

**[Composition and Mixins](./oop/composition-and-mixins.mdx)**

- **Inheritance = "is a"** (`extends`, one parent). **Composition = "has a" / "can do"** (an object holds parts).
- **Favor composition:** you can swap parts, and you avoid deep, rigid class trees.
- A **mixin** is an object of methods copied in with **`Object.assign(Class.prototype, mixin)`**.
- Mixin traps: **name clashes** (the last one wins) and **shared data** (`Object.assign` is shallow).
- A **factory function** returns a new object without `new`. Closures give it **private data**, but each object gets its own copy of the methods.

## 5. Asynchronous JavaScript

**[The Event Loop](./async/event-loop.mdx)**

- JavaScript has **one thread**: one call stack, one thing at a time.
- Slow work runs **outside** (Web APIs, or Node). When it's done, its callback waits in a **queue**.
- **Microtasks:** `.then`, `.catch`, `.finally`, code after `await`, `queueMicrotask`. **Tasks:** `setTimeout`, `setInterval`, I/O.
- The loop: run the script, then **all** microtasks, then **one** task, then all microtasks again.
- So the order is: **normal code, then promises, then timers**. `setTimeout(fn, 0)` is never instant.
- A long loop or endless microtasks **block** everything.

**[Callbacks and Promises](./async/promises.mdx)**

- A **callback** is a function you pass in, to be called later. Nested callbacks become **callback hell**.
- A promise is **pending**, then settles **once**: **fulfilled** (a value) or **rejected** (an error).
- The executor in `new Promise(...)` runs **right away**. `.then` callbacks always run later.
- Each `.then` returns a **new** promise. **Return** inside `.then` so the chain waits.
- One `.catch` at the end handles errors from any step. `.finally` runs either way.
- To promisify: return `new Promise((resolve, reject) => ...)`, and call `resolve` or `reject` from the callback.

**[async and await](./async/async-await.mdx)**

- An `async` function **always returns a promise**. `return` fulfills it, `throw` rejects it.
- `await` pauses **only this function** until the promise settles. The rest of the program keeps running.
- The code before the first `await` runs right away. The rest runs later, as a microtask.
- Handle errors with `try`/`catch` around the `await`.
- Calls that don't depend on each other: start them together with `Promise.all`.
- `forEach` doesn't wait for async callbacks. Use `for...of`, or `Promise.all` with `map`.

**[Promise.all, allSettled, race and any](./async/promise-combinators.mdx)**

- **all:** every value, in the input order. Rejects on the **first** failure.
- **allSettled:** never rejects. Each result is `{ status, value }` or `{ status, reason }`.
- **race:** the first to **settle** wins, even a failure. Good for timeouts (clear the timer).
- **any:** the first **success** wins. If all fail: `AggregateError`.
- None of them **cancel** the slower promises.
- To limit how many run at once: pass **functions**, and run N workers that each take the next task.

**[Timers](./async/timers.mdx)**

- `setTimeout` runs **once**. `setInterval` runs **until cleared**. Both give back an **id** for `clearTimeout` / `clearInterval`.
- The delay is the **shortest** wait, never exact.
- Pass the function, don't call it: `setTimeout(fn, 1000)`.
- **Always clear intervals**, or they run forever and leak memory.
- **Recursive `setTimeout`:** plan the next run when this one ends. No overlap, and the delay can change.
- To show time, read **`Date.now()`**. Don't count ticks.

## 6. Modern JavaScript

**[Destructuring, Spread and Rest](./modern-js/destructuring-and-spread.mdx)**

- **Destructuring:** arrays by **position** (`const [first] = list`), objects by **name** (`const { name } = user`).
- **Rename** with `{ id: userId }`. **Default** with `{ size = 10 }`, used only for `undefined`, not `null`.
- **Spread unpacks** (`[...a, ...b]`, `{ ...user, age: 29 }`). **Rest collects** (`const [head, ...others]`, `function sum(...numbers)`). Rest must be **last**.
- Spread is a **shallow** copy: nested objects are shared.
- `?.` gives `undefined` instead of an error when the left side is `null` or `undefined`.
- `??` falls back only for `null` or `undefined`. `||` falls back for **any** falsy value, including `0` and `""`.

**[Modules](./modern-js/modules.mdx)**

- **Named export:** many per file, `import { add } from "./math.js"`, the name must match (or use `as`).
- **Default export:** one per file, `import anyName from "./logger.js"`, no curly braces.
- **ESM** (`import`/`export`) is the standard and static, so it allows **tree shaking**. **CommonJS** (`require`/`module.exports`) is Node's older, dynamic system.
- ESM imports are **live, read-only bindings**. CommonJS gives the `module.exports` object: a number or string in it is a **copy**, taken at export time.
- A module runs **once**, then it's **cached**: every importer shares the same objects.
- **`import()`** loads a module on demand and gives back a **promise**. It's used for code splitting.

**[Iterators and Generators](./modern-js/iterators-and-generators.mdx)**

- **Iterator:** an object with `next()`, which returns `{ value, done }`.
- **Iterable:** an object with a `[Symbol.iterator]()` method that gives back an iterator. Arrays, strings, Maps and Sets are iterable. **Plain objects are not.**
- `for...of`, spread and destructuring all use the iterator protocol.
- **Generator** (`function*`): calling it runs nothing. Each `next()` runs to the next `yield` and **pauses**. A used-up generator stays done.
- To make a class loopable, add `*[Symbol.iterator]() { ... yield ... }`.
- **Async generator** (`async function*`) + **`for await...of`**: values that arrive over time, handled one by one.

**[Map, Set, WeakMap and WeakSet](./modern-js/map-set-weakmap.mdx)**

- **Map:** any type of key, keeps insertion order, has `size`, loop with `for...of`. Use an **object** for fixed records, a **Map** for dynamic lookups.
- **Set:** unique values, `has` is O(1). `[...new Set(array)]` removes duplicates. Objects are compared by **reference**.
- **WeakMap / WeakSet:** object keys only, held **weakly**, so the object can still be garbage collected. No `size`, no looping.
- A normal Map holds its keys **strongly**: a Map used as a cache can leak memory.
- Real uses: **WeakMap** for caches and private data attached to objects. **Map** for an **LRU cache** (the first key is the oldest).
- `map[key] = value` is a bug: use `map.set(key, value)`.

## 7. JSON and Storage

**[JSON](./json-storage/json.mdx)**

- JSON is **text**. Keys and strings use **double quotes**. No trailing commas, no comments.
- Only **six types**: string, number, boolean, `null`, array, object.
- `JSON.stringify(value, replacer, spaces)`: object → text. `JSON.parse(text, reviver)`: text → **new** objects.
- Lost or changed: `undefined` and functions are **dropped**, `NaN` becomes `null`, Dates become **strings**, Maps and Sets become `{}`.
- Cycles and BigInts **throw** a TypeError. Bad JSON text makes `JSON.parse` throw a **SyntaxError**: use try/catch.
- A **replacer** (or `toJSON`) chooses what goes in. A **reviver** fixes values coming out, like rebuilding Dates.

**[Browser Storage](./json-storage/browser-storage.mdx)**

- `setItem`, `getItem` (gives `null` if missing), `removeItem`, `clear`. Values are **strings only**: use `JSON.stringify` and `JSON.parse`.
- **localStorage** stays until cleared and is shared by all tabs. **sessionStorage** is per tab and is gone when the tab closes. Both are about 5 MB.
- **Cookies** are about 4 KB and are **sent to the server with every request**. `HttpOnly` = JavaScript can't read it, `Secure` = HTTPS only, `SameSite` = protection against CSRF.
- **IndexedDB:** a large, async database in the browser, for offline data and big or structured data.
- **Never** store passwords or secrets. Login tokens are safest in an `HttpOnly` cookie. Users can edit all storage, so the server must check.

## 8. Memory, Errors and Performance

**[Memory and Garbage Collection](./memory-errors/memory-and-garbage-collection.mdx)**

- **Stack:** function frames and simple values, freed when the function returns. **Heap:** objects, freed by the GC.
- **Mark-and-sweep:** start from the roots (globals and the call stack), mark what you can reach, free the rest.
- What matters is **reachability**. Cycles that can't be reached are freed too.
- A **leak** is memory you don't need but can still reach: timers, listeners, growing caches, closures, accidental globals.
- Fix leaks with `clearInterval`, removing listeners, a cache size limit, and **WeakMap** for data tied to an object.
- Find leaks with **heap snapshots**: compare before and after, then follow the **Retainers**.

**[Error Handling](./memory-errors/error-handling.mdx)**

- **`throw new Error("...")`** stops the function. Never throw a plain string: it has no stack.
- **`try`** runs the code, **`catch`** runs only on an error, **`finally`** always runs (even after a `return`).
- An error has **name, message and stack**. Pass `{ cause: error }` to keep the original error.
- Custom errors: `extends Error`, set **`this.name`**, check with **`instanceof`**. Handle what you expect, re-throw the rest.
- `try`/`catch` only catches async errors with **`await`**. Otherwise use `.catch()`.
- Global handlers (`window.onerror`, `unhandledrejection`, `process.on`) are the **last safety net**: log, don't hide.

**[Performance](./memory-errors/performance.mdx)**

- `performance` is a **built-in global** object (browsers and Node.js).
- `performance.now()` = the time in milliseconds, **with decimals**. Measure with `end - start`.
- Run the code **many times** and take the **average**, because one run can be off by chance.
- `Date.now()` has only whole milliseconds, too rough for fast code.

## 9. Testing

**[Unit, Integration and E2E Tests](./testing/unit-integration-e2e.mdx)**

- **Unit test:** one small piece of code, in isolation, usually with no real database. Example: `calculateTotal(100, 3)` should be `300`.
- **Integration test:** several parts working **together**. Example: the login API and the database.
- **E2E test:** the **whole app**, like a real user, in a real browser (Playwright, Cypress). Example: sign up → log in → dashboard.
- Speed: unit is **fastest**, E2E is **slowest**. Debugging: unit is **easiest**, E2E is **hardest**.
- Car: one part → connected parts → the whole car.

## 10. Write Your Own

**[Debounce and Throttle](./write-your-own/debounce-and-throttle.mdx)**

- **Debounce:** run only after the calls **stop** for `delay` ms. Each call does `clearTimeout`, then a new `setTimeout`.
- **Throttle:** run **at most once** per `delay` ms. Keep `last` (the time of the last run) and compare it with `Date.now()`.
- Use `func.apply(this, args)` so `this` and the arguments are passed on.
- Debounce: search box (wait for a pause). Throttle: scrolling (steady updates).

**[Promise.all and Friends](./write-your-own/promise-polyfills.mdx)**

- **all:** every item fulfills, or the **first rejection** wins. **allSettled:** waits for all, **never rejects**.
- **race:** the first to **settle** wins. **any:** the first to **fulfill** wins, `AggregateError` if all fail.
- Save each result at **`results[index]`**, never `push`, so the order matches the input.
- Count finished items with a **counter**, not `results.length`.
- Wrap every item with **`Promise.resolve(item)`** so plain values work. Handle the **empty** list.
- A promise settles **once**, so extra `resolve` or `reject` calls do nothing, and nothing gets cancelled.

**[call, apply and bind Polyfills](./write-your-own/call-apply-bind-polyfills.mdx)**

- The trick: **`this` is the object before the dot**. Put the function on the context, call it, delete it, return the result.
- Use a **Symbol** key. Use `globalThis` for `null` or `undefined`. Wrap primitives with `Object()`.
- **myApply** = myCall with **one array** of arguments (`null` means no arguments).
- **myBind** saves the function and the first arguments, and returns a function that runs `apply` with **saved arguments first**.
- With **`new`**, a bound function ignores its `this`: check `this instanceof boundFunction` and link the prototype.
- Once bound, `this` can't be changed again, not even by `call` or another `bind`.

**[Array Method Polyfills](./write-your-own/array-method-polyfills.mdx)**

- Add polyfills with a **normal function**, so `this` is the array. Never an arrow function.
- The callback gets **`(item, index, array)`**. `map`, `filter`, `forEach` and `find` also take a `thisArg`.
- **map:** a new array, same length. **filter:** keep items where the callback is **truthy**. **find:** the first match, or `undefined`.
- **reduce:** check **`arguments.length`** for the start value. No start value: use the first item and loop from index 1. Empty with no start value: **TypeError**.
- **flat:** default depth **1**. Recurse with `depth - 1`, or use a stack.
- **forEach** returns `undefined`, can't `break`, and doesn't wait for async callbacks.

**[Deep Clone and Deep Equal](./write-your-own/deep-clone-and-deep-equal.mdx)**

- **deepClone:** return primitives as they are. For objects, make a new `[]` or `{}` and deep-clone each value into it.
- Check **`value === null`** first: `typeof null` is `"object"`.
- **Dates:** `new Date(value.getTime())`. **Cycles:** a `WeakMap` from original to copy, saved **before** going deeper.
- **deepEqual:** `Object.is` first (so `NaN` equals `NaN`), then same kind, same key count, and every key equal by recursion.
- In real code, **`structuredClone`** is enough. It can't copy functions, and class objects lose their methods.

**[Event Emitter](./write-your-own/event-emitter.mdx)**

- Store a **Map** from each event name to an **array of listener functions**.
- **on** pushes, **off** removes with `indexOf` + `splice` (it needs the **same function**), **emit** calls each listener with `...args`.
- **once** adds a **wrapper** that calls `off` on itself first, then calls the real listener.
- In `emit`, loop over **a copy** (`listeners.slice()`), so a listener that removes itself doesn't skip the next one.
- `emit` is **synchronous**: listeners run right away, in the order they were added. A throwing listener stops the rest.

**[Flatten and Memoize](./write-your-own/flatten-and-memoize.mdx)**

- **flatten:** for each item, if it's an array and depth is above 0, flatten it with **depth - 1** and add its items. Built in: `array.flat(depth)`.
- **flattenObject:** carry a **prefix**, walk into plain objects, and save everything else under `prefix.key`. Check for `null`.
- **memoize:** a `Map` cache in a **closure**, a key from `JSON.stringify(args)`, and check with **`cache.has`**.
- **curry:** collect arguments until there are at least **`fn.length`**, then call `fn`. Use `concat`, never change the shared array.
- `sum(1)(2)(3)()`: there's no fixed length, so an **empty call** means stop.

## 11. Guess the Output

**[Output: Scope and Hoisting](./guess-the-output/output-scope-and-hoisting.mdx)**

- **Setup pass first:** `var` starts as `undefined`, function declarations are ready, `let` and `const` are locked (the TDZ).
- A `let` or `const` read before its line throws **ReferenceError: Cannot access 'x' before initialization**.
- A **function expression** is a variable: calling it too early throws **TypeError: x is not a function**.
- `var` ignores blocks. `let` and `const` stay inside their `{ }`.
- An inner name **shadows** the outer one in its whole scope, even on the lines above it.
- `var` in a loop = **one shared** variable. `let` in a loop = **a new one each turn**.

**[Output: this](./guess-the-output/output-this.mdx)**

- **Look at the call:** in `obj.fn()`, `this` is `obj`, the object right before the last dot.
- A **plain call** `fn()` has no object: `this` is `undefined` (strict) or the global object (sloppy).
- Passing `obj.fn` as a **callback** loses `this`. Wrap it in an arrow or use `bind`.
- **Arrow functions** take `this` from where they were written. `call`, `apply` and `bind` can't change it.
- `call(obj, a, b)` and `apply(obj, [a, b])` run now. `bind(obj)` returns a new function, and a second `bind` can't change its `this`.
- Class code is always **strict**, so a lost class method throws a TypeError.

**[Output: Event Loop](./guess-the-output/output-event-loop.mdx)**

- Order: **sync code → all microtasks → one timer → all microtasks → next timer**.
- The `new Promise` body and an `async` function (up to its first `await`) run **right away**.
- Microtasks: `.then`, `.catch`, `.finally`, the code after `await`, and `queueMicrotask`.
- The next `.then` in a chain is queued only when the one before it **finishes**, so chains take turns.
- Timers: shortest delay first. Equal delays run in the order they were set. `0` ms still waits.

**[Output: Coercion and Objects](./guess-the-output/output-coercion-and-objects.mdx)**

- `===` never converts. `==` converts: objects become strings, then booleans and strings become numbers. `null` only loosely equals `undefined`.
- `+` with a string **joins**. `-`, `*` and `/` always turn things into **numbers**.
- Only 8 falsy values. `[]`, `{}` and `"0"` are all **truthy**.
- `typeof null` and `typeof []` are both `"object"`. Use `value === null` and `Array.isArray`.
- Objects compare and copy **by reference**. Spread copies **one level** only.
- `sort()` compares items as **strings**, and `map(parseInt)` passes the index as the radix.

## 12. TypeScript

**[TypeScript Basics](./typescript/typescript-basics.mdx)**

- **TypeScript = JavaScript + types.** Mistakes are caught **before** the code runs.
- Core types: `string`, `number`, `boolean`, `null`, `undefined`.
- **`any`** turns checking off. **`unknown`** makes you check the type before using the value.
- Arrays: `number[]`, `string[]`, `(number | string)[]`.
- `type User = { ... }` describes an object. `?` makes a property or parameter **optional**.
- **`void`**: returns nothing. **`never`**: never finishes (always throws, or loops forever).
- Extend a **type** with `&`. Extend an **interface** with `extends`.

**[Unions and Narrowing](./typescript/narrowing-and-unions.mdx)**

- A **union** (`string | number`) means the value is one of these types.
- With a union, TypeScript only allows what works for **every** type in it.
- **Narrowing:** check with `typeof`, and inside the `if`, TypeScript knows the exact type.
- The same `typeof` check makes an `unknown` value safe to use.

**[Generics](./typescript/generics.mdx)**

- `any` loses the type. A union keeps only "one of these types", not the exact one.
- A **generic** (`<T>`) is a type placeholder. It becomes the type you call the function with.
- `function first<T>(arr: T[]): T` works for any array, and returns the **exact** item type.
- TypeScript can usually work out `T` by itself: `first([1, 2, 3])` is a `number`.
- Any name works, but `T` is the convention.

**[Utility Types](./typescript/utility-types.mdx)**

- Utility types make a **new type from an existing one**. Define `User` once, derive the rest.
- **`Partial`** = all optional, **`Required`** = all required, **`Readonly`** = no changes (TypeScript only, shallow).
- **`Pick`** = keep these fields, **`Omit`** = remove these fields, **`Record<Keys, Value>`** = an object with these keys.
- **`ReturnType<typeof fn>`** and **`Parameters<typeof fn>`**. Use `Awaited` for async functions.
- **`keyof T`** = the key names as a union. A **mapped type** `{ [K in keyof T]: ... }` loops over them.
