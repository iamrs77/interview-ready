## What is abstraction?

**Abstraction** means hiding the details that don't matter, and showing only what the user needs.

When you drive a car, you press the start button. You don't need to know how the engine starts inside.

```js
class Car {
    start() {
        this.#startEngine();
        console.log("Car is ready to drive.");
    }

    // private method: hidden from outside
    #startEngine() {
        console.log("Engine started");
    }
}

const car = new Car();
car.start();
// Engine started
// Car is ready to drive.
```

- Outside code only sees `start()`.
- `#startEngine()` is a **private method** (its name starts with `#`), so outside code can't call it.
- Later, the class can change how the engine starts, and the code that calls `start()` stays the same.

## Abstract classes and interfaces

- **Abstract class:** a class you can't create objects from directly, but other classes can extend it. It may have **abstract methods**: methods with no code, which child classes **must** write.
- **Interface:** a blueprint of the methods and properties a class must have, with no code at all.

JavaScript has neither of these built in. TypeScript has both: `abstract class` and `interface`.

<Callout title="Remember this" type="success">
  - **Abstraction** = show only what the user needs, and hide how it works.
  - A **private method** (`#startEngine()`) hides the details. Outside code calls only the simple method (`start()`).
  - **Abstract class:** can't be created directly, only extended. Child classes must write its abstract methods.
  - **Interface:** a list of methods and properties a class must have.
  - JavaScript has no abstract classes or interfaces. **TypeScript** has both.
</Callout>
