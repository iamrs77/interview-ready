## What is polymorphism?

**Polymorphism** means the same method call can behave differently, depending on the object. Toys can act differently: call `move()` on a toy car and it drives, call it on a robot and it walks.

There are two kinds: **method overloading** and **method overriding**.

## Method overloading

Same method name, **different parameters**, in the **same class**. The return type can be different too.

- Supported in **TypeScript**, not in JavaScript. In JavaScript, a second method with the same name just replaces the first one.
- Unlike Java and C++, TypeScript allows only **one implementation**. You write the overload signatures (only the types), then one method body.
- That one body must handle **every** overload variation.

```ts
class Greeter {
    // Overload signatures
    greet(name: string): void;
    greet(age: number): void;

    // Single implementation
    greet(value: string | number): void {
        if (typeof value === "string") {
            console.log(`Hello, ${value}`);
        } else {
            console.log(`You are ${value} years old`);
        }
    }
}

const g = new Greeter();
g.greet("Rohit"); // Hello, Rohit
g.greet(27); // You are 27 years old
```

## Method overriding

Same method name and parameters, **redefined in a child class**. JavaScript doesn't check types. In TypeScript, the child's return type must be compatible with the parent's.

```js
class Toy {
    move() {
        console.log("The toy moves");
    }
}

class ToyCar extends Toy {
    move() {
        console.log("The car drives fast!");
    }
}

class Robot extends Toy {
    move() {
        console.log("The robot walks!");
    }
}

let car = new ToyCar();
let robot = new Robot();

car.move(); // The car drives fast!
robot.move(); // The robot walks!
```

Both are toys, and both get the same call, `move()`. Each one does its own thing.

<Callout title="Remember this" type="success">
  - **Polymorphism** = the same method call behaves differently, depending on the object.
  - **Overloading:** same name, different parameters, same class. Only in **TypeScript**: several signatures, **one** implementation that handles them all.
  - **Overriding:** a child class redefines a parent's method with the same name and parameters.
</Callout>
