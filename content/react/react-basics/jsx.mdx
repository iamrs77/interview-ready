## The idea

**JSX** lets you write HTML-like markup inside JavaScript. It looks like HTML, but it is **not HTML and not a string**. Before the code runs, a build tool turns every JSX tag into a plain JavaScript function call.

Think of shorthand, like writing "ASAP" instead of "as soon as possible": quicker to write, and expanded into the long form before anyone uses it.

## What JSX turns into

This line of JSX:

```jsx
const title = <h1 className="title">Hello</h1>;
```

is turned by the build tool (Babel, SWC or esbuild) into a function call: `jsx("h1", { className: "title", children: "Hello" })`, with `jsx` imported from `react/jsx-runtime`.

Before React 17, it became `React.createElement("h1", { className: "title" }, "Hello")`. That's why old React files start with `import React from "react"`. The call returns a plain JavaScript object, called a **React element**. Simplified:

```js noRun
const title = {
    type: "h1",
    props: {
        className: "title",
        children: "Hello",
    },
};
```

A React element is a **description** of what to show, not a real DOM node. It is cheap to make, and `react-dom` turns it into real DOM nodes later.

## JavaScript inside curly braces

Inside JSX, **curly braces `{ }`** switch back to JavaScript. You can put any **expression** there: anything that gives back a value.

```jsx
function Profile() {
    const user = { name: "Ana", photoUrl: "/ana.png", unread: 3 };

    return (
        <div>
            <img src={user.photoUrl} alt={user.name} />
            <h2>{user.name.toUpperCase()}</h2>
            <p>{user.unread} unread messages</p>
            <p>{user.unread > 0 ? "Check your inbox" : "All caught up"}</p>
        </div>
    );
}
```

Use quotes for a plain string (`alt="Profile photo"`) and braces for everything else.

**Statements don't work** inside braces: no `if`, `for` or `const`. Use the `? :` operator, `&&`, or `map` instead. See [Conditional Rendering](./conditional-rendering.mdx) and [Lists and Keys](./lists-and-keys.mdx).

## The rules

| Rule | Wrong | Right |
| --- | --- | --- |
| Return **one** parent element | `return <h1 /><p />` | Wrap them: `<div>...</div>` or `<>...</>` |
| **Close every tag**, even empty ones | `<img src={url}>` | `<img src={url} />` |
| Attributes use **camelCase** | `onclick`, `tabindex` | `onClick`, `tabIndex` |
| `class` and `for` have other names | `class="box"`, `for="email"` | `className="box"`, `htmlFor="email"` |
| `style` takes an **object** | `style="color: red"` | `style={{ color: "red" }}` |
| Comments go in braces | `<!-- note -->` | `{/* note */}` |

Why **one parent**? A function returns **one** value, and JSX becomes one function call. Two tags side by side would be two values.

## Fragments

When you need one parent but don't want an extra `<div>` on the page, use a **Fragment**: `<>` and `</>`. It groups the elements and adds nothing to the page. An extra `<div>` can break the HTML: a `<dl>` list expects `<dt>` and `<dd>` directly inside it.

When you need a `key` on a fragment, in a list, write the long form: `<Fragment key={item.id}>`.

## What different values show

| Value in `{ }` | What appears on the page |
| --- | --- |
| A string or a number | The text. `0` shows as `0` |
| `true`, `false`, `null`, `undefined` | Nothing |
| An array | Each item, one after another |
| A React element | That element |
| A plain object | An error: "Objects are not valid as a React child" |

The "nothing" row is what makes `{isOpen && <Menu />}` work. The `0` row is the famous trap: see [Conditional Rendering](./conditional-rendering.mdx#the-0-trap).

## JSX protects you from injected HTML

Text in curly braces is **escaped**: React shows it as text, never as HTML. This stops **XSS** (cross-site scripting), where a user types HTML or a script into a form and it runs on other people's screens.

To insert real HTML, you must use **`dangerouslySetInnerHTML={{ __html: html }}`**. Only do it with HTML you trust, or that you cleaned with a library like DOMPurify.

## Common mistakes

- **`return` on its own line.** JavaScript adds a `;` right after `return`, so the function returns `undefined`. Start the JSX on the same line: `return (`.
- **Two elements without a parent.** The build fails with "Adjacent JSX elements must be wrapped in an enclosing tag". Wrap them in a Fragment.
- **An `if` or `for` inside braces.** Only expressions work. Use `? :`, `&&` or `map`.
- **Putting an object in the JSX**, like `{user}`. Show one of its fields: `{user.name}`.

## In the interview

> "JSX is a syntax that lets me write HTML-like markup in JavaScript. It isn't HTML: a compiler like Babel turns each tag into a function call, `jsx()` today or `React.createElement()` in older code, and that call returns a plain object describing the element. Curly braces let me put any JavaScript expression inside, and text in braces is escaped, which protects against XSS."

**Likely follow-up:** "Can you write React without JSX?"

**Answer:** "Yes. JSX is only a nicer way to write `React.createElement(type, props, ...children)`. Without a build step, I'd call `createElement` myself. It works, but nested UI gets hard to read, so almost everyone uses JSX."

**Another follow-up:** "Why `className` and not `class`?"

**Answer:** "`class` is a reserved word in JavaScript, and JSX attributes follow the DOM property names, which use `className`. For the same reason it's `htmlFor` instead of `for`."

<Callout title="Remember this" type="success">
  - JSX is **not HTML**: each tag becomes a function call, `jsx()` (React 17+) or `React.createElement()`, that returns a plain **object** (a React element).
  - `{ }` holds any JavaScript **expression**. No `if` or `for` inside; use `? :`, `&&` or `map`.
  - Rules: **one parent** (or a Fragment `<>...</>`), **close every tag**, **camelCase** attributes, `className`, `htmlFor`, `style={{ }}` with an object.
  - `true`, `false`, `null` and `undefined` show **nothing**. `0` **shows "0"**. A plain object throws an error.
  - Text in braces is **escaped**, so it's safe from XSS. `dangerouslySetInnerHTML` skips that protection.
</Callout>
