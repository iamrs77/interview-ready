## The three kinds of React questions

React interviews, for frontend and full-stack roles, ask three kinds of questions:

| Kind | What it sounds like | Where to practice |
| --- | --- | --- |
| **Explain it** | "What is the virtual DOM?" "Why do lists need keys?" "When does `useEffect` run?" | The lessons in sections 1 to 8 |
| **Build it** | "Build a todo list." "Build a search box with autocomplete." 45 to 60 minutes, often in a live editor | [9. Build It](./build-it/todo-list.mdx) |
| **Predict and debug** | "What does the screen show after one click?" "Why does this timer stop at 1?" | [10. Predict and Debug](./predict-and-debug/puzzles-state-updates.mdx) |

As in every interview, explain **why**. Name the rule ("state is a snapshot for this render"), then walk through what React does, step by step.

## The order to study

Each section builds on the ones before it, so go in sidebar order:

| Section | Why it comes here |
| --- | --- |
| 1. React Basics | Components, JSX, props, lists and events: the words every other lesson uses |
| 2. State and Rendering | How state works and when React re-renders: the root of most tricky questions |
| 3. Hooks | `useEffect`, `useRef`, context, `useMemo` and custom hooks: the most asked topic |
| 4. Component Patterns | Composition, error boundaries, portals, and class components for older code |
| 5. Performance | Why components re-render, `React.memo`, and code splitting |
| 6. Data and State Management | Fetching data, Redux, TanStack Query, and where state should live |
| 7. Modern React | Transitions, server rendering, Server Components and React 19 |
| 8. Routing, Testing and TypeScript | The tools around React that job posts list |
| 9. Build It | Machine-coding questions, built step by step |
| 10. Predict and Debug | Puzzles about state updates, effects, stale closures and keys |

React is JavaScript. If closures, `this`, promises or array methods feel shaky, do the [JavaScript track](../javascript/index.mdx) first: closures alone explain half of the tricky React questions.

The [Cheat Sheet](./cheat-sheet.mdx) and the [Last-Minute Revision](./revision.mdx) page are for the night before.

## Running the code

The code in this track is React, so it needs a page to show its result. The quickest way to try it on your computer, with [Node.js](https://nodejs.org) installed:

```bash
npm create vite@latest react-practice -- --template react
cd react-practice
npm install
npm run dev
```

Open the address it prints, then paste a component into `src/App.jsx`. Name the component `App` and keep `export default App` at the bottom.
