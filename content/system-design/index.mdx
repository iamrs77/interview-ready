## What is a system design interview?

In a system design interview, you are asked to design a big software system. For example:

- "Design a URL shortener like bit.ly."
- "Design a chat app like WhatsApp."
- "Design a video site like YouTube."

You get about **45 to 60 minutes**. You talk, and you draw boxes and arrows on a whiteboard.

There is **no single right answer**. The interviewer wants to see how you think:

- Do you understand **what** to build before you start building?
- Can you break a big problem into **small parts**?
- Do you know the common tools (databases, caches, queues) and **when to use each one**?
- Can you explain the **tradeoffs**? A tradeoff is what you gain and what you lose when you make a choice. For example: "A cache makes reads faster, but the data can be a little old."
