**[Git Basics](./index.mdx)**

- **Git** is the version control system on your computer. **GitHub** is a website that hosts Git repositories.
- Three stages: **modified** (working directory) → `git add` → **staged** (staging area) → `git commit` → **committed**.
- The staging area is a **draft** of the next commit, so you choose what goes in.
- A new repository has one branch: `master` by default, `main` on GitHub.
- **HEAD** = where you are now: your current branch and its latest commit.

**[Starting a Repository](./starting-a-repository.mdx)**

- `git config --global user.name` and `user.email` set who you are. `git config --list` shows the settings.
- `git init` starts a **new** repository in the root folder of your project.
- `git remote add origin <url>` connects it to GitHub. `origin` is only a name for the URL.
- `git clone <url>` copies an **existing** repository with all its history, and sets up `origin` for you.
- `git remote -v` shows the remotes and their URLs.

**[Saving Changes](./saving-changes.mdx)**

- The loop: `git status` → `git add` → `git commit -m "message"`.
- `git add <file>` stages one file. `git add .` stages everything in the current folder and below.
- `git reset <file>` **unstages** a file. The changes stay in the file.
- `git commit` saves only what is **staged**.
- `git log` shows the full history. `git log --oneline` shows the short ID and message of each commit.

**[Branches](./branches.mdx)**

- A branch is a **separate line of work**, and under the hood just a name that points to a commit.
- `git branch -a` shows local and remote branches. `*` marks the current one.
- `git branch <name>` creates a branch. `git checkout <name>` switches to it.
- `git checkout -b <name>` creates a branch **and** switches to it.
- `git branch -d` is the safe delete. `git branch -D` force deletes, even unmerged work.

**[Merge and Rebase](./merge-and-rebase.mdx)**

- `git merge feature` brings `feature` into the **current** branch.
- **Fast-forward:** the current branch has no new commits, so Git just moves its name forward. Otherwise Git makes a **merge commit**.
- `git rebase main` (on `feature`) replays your commits **on top of** `main`. The history becomes a straight line.
- Rebased commits are **new commits** (D becomes D') with new IDs.
- **Golden rule:** never rebase commits that others already have. Merge is always safe.

**[Push, Pull and Fetch](./push-pull-fetch.mdx)**

- `git push` sends your commits **up**. `git fetch` and `git pull` bring commits **down**.
- `git fetch` only downloads. It **doesn't change** your branch or files.
- `git pull` = `git fetch` + `git merge` into your **current** branch.
- `git pull origin rohit` merges origin's `rohit` into the branch you're on. `git push origin rohit` sends your `rohit` to origin's `rohit`.
- Another dev's branch: `git fetch` → `git checkout <their-branch>` → `git pull` for new commits.

**[Checkout, Revert and Reset](./undoing-changes.mdx)**

- **Checkout** = look at an old version. **Revert** = undo but keep history. **Reset** = move the branch back.
- `git checkout <commit-id>` puts you in **detached HEAD**. `git checkout <branch>` takes you back.
- `git revert <commit-id>` adds a **new commit** that reverses it. Safe on shared branches.
- `git reset`: `--soft` keeps changes **staged**, `--mixed` (default) keeps them **unstaged**, `--hard` **discards** them.
- `git reset --soft HEAD~1` undoes the last commit and keeps its changes. `--hard HEAD~1` throws them away.

**[Stash](./stash.mdx)**

- `git stash` saves **uncommitted** changes aside and cleans the working directory.
- New (untracked) files are **not** stashed unless you use `git stash -u`.
- `git stash list` shows the stashes. The newest is `stash@{0}`.
- `git stash pop` applies **and removes** the stash. `git stash apply` applies and **keeps** it.

**[Cherry-Pick](./cherry-pick.mdx)**

- `git cherry-pick <commit-id>` copies **one commit** onto your current branch.
- The copy is a **new commit** (E becomes E') with a new ID. The other branch doesn't change.
- Use it for one change, like a bug fix, without merging the whole branch.
- Find the ID with `git log --oneline <branch>`.
- Conflicts: fix → `git add` → `git cherry-pick --continue`, or `git cherry-pick --abort` to cancel.
