## The idea

Before you can save work with Git, you need three things:

1. Tell Git **who you are**, so your name is on your commits.
2. **A repository**: start a new one, or copy one that already exists.
3. To share your work, **connect it to GitHub**.

## How it works

### Tell Git who you are: git config

```bash
# Your name and email are saved in every commit you make.
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# See the settings Git is using.
git config --list
```

`--global` saves the setting for every repository on your computer. Without it, the setting is only for the repository you're in.

### Start a new repository: git init

Run it in the **root folder** of your project:

```bash
cd my-project
git init
```

Git creates the hidden `.git` folder and starts tracking the project. Nothing is saved yet: you still need to add and commit your files (see [Saving Changes](./saving-changes.mdx)).

### Connect it to GitHub: git remote add

A **remote** is a copy of your repository on a server, like GitHub.

```bash
# git remote add <name> <url>
git remote add origin https://github.com/iamrs77/NestJS-API.git

# See the remotes and their URLs.
git remote -v
```

- `<name>` is a short name (alias) for the remote. `origin` is the name everyone uses, by convention.
- `<url>` is the address of the repository on GitHub, GitLab or another Git server.

From now on, you can write `origin` instead of the full URL.

`git remote -v` shows each remote twice, once for fetch and once for push:

```text
origin  https://github.com/iamrs77/NestJS-API.git (fetch)
origin  https://github.com/iamrs77/NestJS-API.git (push)
```

### Copy an existing repository: git clone

```bash
git clone https://github.com/iamrs77/NestJS-API.git
```

This downloads the whole repository, with all its history, into a new folder called `NestJS-API`. It also sets up the remote as `origin` for you, so you don't need `git remote add`.

| You have | Run |
| --- | --- |
| A project on your computer that isn't in Git yet | `git init`, then `git remote add origin <url>` |
| A repository that is already on GitHub | `git clone <url>` |

<Callout title="Remember this" type="success">
  - `git config --global user.name` and `user.email` set who you are. `git config --list` shows the settings.
  - `git init` starts a **new** repository in the root folder of your project.
  - `git remote add origin <url>` connects it to GitHub. `origin` is only a name for the URL.
  - `git clone <url>` copies an **existing** repository with all its history, and sets up `origin` for you.
  - `git remote -v` shows the remotes and their URLs.
</Callout>
